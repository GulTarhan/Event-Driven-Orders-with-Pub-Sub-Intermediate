About this project

Slice Queue is a class demo for ISIT 225 Cloud Computing.

On this website you order pizza like a normal customer. Technically each checkout publishes a message to a queue. A processor (the future Cloud Function) validates it and stores the order. Bad messages are retried and can end up in a dead-letter list.

Local now: Flask + file storage.
Cloud later (free tier): Pub/Sub topic orders → Cloud Function → Firestore.
